## 🚀 Featured Projects

### 🧠 Shearaion Course Creation API
> AI pipeline that auto-generates full courses from GitHub repos, PDFs, and code files

- LangGraph state machine with human-in-the-loop review checkpoints
- RAG pipeline using Milvus vector store + OpenAI embeddings
- Multi-format parser supporting 8+ languages via Tree-sitter
- Switchable LLM providers: Gemini 2.5 Pro / GPT-4o

**Stack:** Python · Django · LangGraph · RAG · Milvus · Gemini AI · AWS S3

---

### 🛡️ QA Risk Analysis Platform
> Weighted risk scoring engine that auto-classifies regression risk from code changes

- Scores changes by service criticality, change type, and test coverage
- Classifies risk as HIGH / MEDIUM / LOW automatically
- Full stack: Django REST API + React TypeScript frontend + JWT auth

**Stack:** Django · DRF · React · TypeScript · PostgreSQL · JWT
